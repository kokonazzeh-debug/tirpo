How to get the APK without Android Studio
1. Create a free account on github.com and a new repository (e.g. nazzeh-turbo).
2. Upload ALL files of this folder (including the hidden .github folder) to it.
3. Open the Actions tab -> "Build APK" -> wait ~5 minutes.
4. Open the finished run -> Artifacts -> download nazzeh-turbo-apk (a zip containing app-debug.apk).
5. Unzip it, copy app-debug.apk to the phone, install (allow "install unknown apps").
